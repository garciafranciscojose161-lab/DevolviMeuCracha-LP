03. Palette

Sistema de Cores

Trabalhamos com tons profundos de aqua e darkness para o background, permitindo que o foco caia inteiramente no Dourado (Ação Primária) e no Verde Neon (Conversão/Sucesso). Contrastes validados AAA para textos claros sobre fundo escuro.

Ação & Marca (Accent Roles)

Gold Primary
#B3A275

Role: Semântica Primária.

Rules: Botões Padrões, Links Actives, Bordas em Foco, Textos Gradientes.

Pulse Green
#00FF5F

Role: Semântica Secundária/Sucesso.

Rules: Botões com Glow (Pulsantes), Badges de Status, Highlights urgentes.

Buy Gradient
Gradient Map

Role: CTA de Máxima Conversão.

Rules: Usado apenas no botão principal de venda/inscrição (btn-glow).

Fundos & Superfícies (Base Roles)

Deep Aqua Base
#102A2C

Role: Base de Fundo / Neutral

Rules: Fundo padrão de 80% das seções. Gera clima premium corporativo.

#0A1A1C

Role: Contraste Profundo

Rules: Fundo de Headers, Footers, e Popups Modais.

06. Imersão & Microinterações

Motion System

.fadeSlideIn

Uma transição CSS suave usando Cubic-Bezier. Acionada por JS (Intersection Observer) para que o conteúdo suba lentamente conforme a tela é rolada, engajando a leitura.

.btn-glow

Uma animação pulse-glow infinita feita simulando um espalhamento de box-shadow de rgba(0,255,95,0) a (0.5), guiando os olhos instantaneamente para o checkout.

Cursor Effect

Classes .cursor-dot e .cursor-outline substituem o mouse do SO. A aura expande com a classe .cursor-hover nos elementos interativos.

.liquid-blob

Formas absolutas renderizadas sob os elementos. Elas rotacionam e transladam suavemente via keyframes, criando o aspecto mutável do projeto.
