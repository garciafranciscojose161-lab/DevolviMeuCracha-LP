06. Motion System

A Lógica por trás do "Wow"

Scroll Reveal

Utilizamos o IntersectionObserver nativo. Os elementos perdem o blur e deslizam para cima de forma elegante quando surgem na tela.

Flashlight Glow

Os cards acompanham o mouse passando propriedades X/Y para o CSS, gerando um brilho radial sutil por trás do contêiner branco.

Border Beam

Botões primários possuem um conic gradient girando atrás de um padding de 1.5px. Cria um highlight infinito premium.

3D Card Stack

Uso de CSS transitions (translateY e scale) orquestradas pelo Javascript para gerar um loop visual super atrativo de profundidade.
